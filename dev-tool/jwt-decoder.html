JWT Decoder

Decode and inspect JSON Web Tokens quickly. This responsive tool shows header and payload data in a readable format.

Paste a JWT and click Decode to see header and payload details.
Status: Ready Segments: 0

How it works

A JWT contains three parts: header, payload, and signature. This tool decodes the first two parts so you can inspect the token contents without verifying the signature.

Security note

Never paste sensitive tokens on untrusted pages. This tool only decodes values locally in your browser and does not transmit data to any server.
