HTML Entity Encoder / Decoder

Convert text to HTML entities and decode entities back into normal text with a simple responsive interface.

Mode: Encode Length: 0

How to use

Paste plain text to convert special characters into HTML entities, or paste entity-encoded text to decode it back. The tool is optimized for readability and mobile use.

Useful notes

Encoding is useful for safely displaying reserved HTML characters in content. Decoding is handy when you need the original text from encoded markup.
