Base64 Encoder / Decoder

Quickly encode plain text to Base64 or decode Base64 into readable text. The layout is responsive and ready for any screen.

Input
Output
Mode: Encode Length: 0

How to use

Enter text in the input field. Choose Encode to convert text into Base64, or Decode to convert Base64 back to plain text. Copy your result with one click.

Best practices

Use this tool for small snippets, tokens, or quick testing. If decoding fails, verify that the Base64 input is complete and valid.
